
# Acculum — Code Spark at AMC College of Engineering Resources

## Challenge

**Problem Statement 1 — Personalized Learning**

> Design a learning platform that adapts to each student's pace, progress, and interests, while helping facilitators understand when and how to intervene.

## Project

**Acculum**

Acculum is an AI-assisted personalized learning platform connecting a student learning experience with a facilitator intervention workflow.

Core loop:

**Student activity → Learning data → Signal detection → Facilitator insight → Intervention → Reassessment**

## Personalization

Acculum combines explicit student interests with learning performance.

Supported interests include:

**Cricket, Music, Gaming, Robotics, Football, Art, Science, Reading and Technology.**

Examples can be adapted to interests such as:

- Probability + Cricket
- Electricity + Robotics
- Fractions + Music

Performance recommendations currently follow:

- **85%+** → Progress / next topic
- **50–84%** → Targeted practice
- **Below 50%** → Revision / reinforcement

## Learning Signals

The facilitator workflow considers:

- Quiz performance
- Repeated errors
- Repeated attempts
- Hints and help-seeking
- AI companion activity
- Lesson completion
- Skipped or incomplete lessons
- Engagement patterns
- Confidence/performance mismatch
- Hidden strengths
